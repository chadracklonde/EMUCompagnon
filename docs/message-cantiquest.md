# Message à envoyer à Cantiquest (demande d'autorisation)

**À :** courrier@cantiquest.org (adresse affichée sur la page d'accueil de cantiquest.org)
**Objet :** Demande d'autorisation – utilisation des fichiers MIDI des Chants de Victoire dans l'application ÉMU Compagnon

Bonjour,

Je développe **ÉMU Compagnon**, une application mobile gratuite destinée aux fidèles de l'Église Méthodiste Unie. Elle contient la Bible, les cantiques « Chants de Victoire », un dictionnaire biblique et une liturgie.

Pour aider les fidèles à apprendre les chants et à en suivre le rythme, je souhaiterais intégrer dans l'application les fichiers **InstruMidi** (polyinstrumentaux) que vous mettez à disposition sur https://www.cantiquest.org/CV.htm, soit 129 fichiers. Chaque fichier serait lié au cantique correspondant, avec un lecteur permettant de l'écouter, d'en ralentir le tempo et de le répéter.

Pourriez-vous me dire :
1. si vous m'autorisez à embarquer ces fichiers MIDI dans l'application (distribuée gratuitement) ;
2. si ces arrangements ont été réalisés par Cantiquest, et sinon à qui je dois m'adresser ;
3. s'il existe des conditions (mention de la source, par exemple « Musique : Cantiquest.org ») ou des chants que vous ne souhaitez pas voir repris ;
4. si une autorisation écrite par retour de courriel vous convient.

Je mentionnerai volontiers Cantiquest comme source dans l'application. Merci beaucoup pour votre travail de partage de ces chants et pour votre réponse.
