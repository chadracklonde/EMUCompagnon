# Politique de confidentialité — ÉMU Compagnon

*Dernière mise à jour : 25 août 2026*

## Résumé en une phrase

ÉMU Compagnon ne collecte aucune donnée personnelle : tout ce que vous
créez dans l'application (favoris, notes, surlignages, progression de
lecture, réglages) reste stocké uniquement sur votre appareil.

## Qui édite cette application ?

ÉMU Compagnon est développée par Chadrack Londe, à titre personnel,
pour la communauté de l'Église Méthodiste Unie. Ce n'est pas une
application commerciale.

Contact : chadracklonde@outlook.com

## Quelles données l'application stocke-t-elle ?

Toutes les données suivantes sont enregistrées **uniquement dans une
base de données locale sur votre appareil**, jamais transmises à un
serveur, jamais accessibles au développeur :

- Les versets, cantiques et entrées de dictionnaire que vous marquez
  en favori
- Les notes personnelles que vous rédigez
- Les surlignages de couleur que vous appliquez aux versets
- Votre progression dans le plan de lecture biblique
- Vos préférences d'affichage (thème, taille du texte, langue, police)
- L'heure choisie pour le rappel de lecture quotidien

Aucune de ces informations n'est envoyée où que ce soit. Si vous
désinstallez l'application, ces données sont supprimées.

## L'application communique-t-elle avec un serveur ?

Deux fonctions, toutes deux optionnelles et déclenchées uniquement par
vous, impliquent une connexion réseau :

1. **Vérification des mises à jour de contenu** : à votre demande
   explicite (bouton « Vérifier les mises à jour » dans les réglages),
   l'application interroge un dépôt public sur GitHub pour savoir si
   une nouvelle version de la Bible/des cantiques/du dictionnaire est
   disponible. Aucune donnée vous concernant n'est envoyée lors de
   cette vérification — l'application se contente de télécharger un
   fichier public.
2. **Partage** : quand vous utilisez le bouton « Partager » (verset en
   image, sauvegarde de vos données), l'application ouvre le menu de
   partage natif de votre téléphone. Ce que vous choisissez de
   partager, et avec qui, dépend entièrement de vous — l'application
   elle-même n'envoie rien à un serveur.

## Notifications

Le rappel de lecture quotidien est programmé **entièrement sur votre
appareil**, sans passer par un serveur externe. Vous pouvez le
désactiver à tout moment dans les réglages.

## Permissions demandées

- **Notifications** : pour le rappel de lecture quotidien (optionnel,
  désactivable).
- **Stockage/fichiers** : uniquement pour importer une sauvegarde que
  vous avez vous-même exportée précédemment, ou pour enregistrer les
  fichiers que vous partagez.

Aucune permission de localisation, caméra, microphone, contacts ou
identité n'est demandée.

## Services tiers utilisés

L'application utilise des composants techniques standards (bibliothèques
Flutter open source) pour le stockage local, les notifications et le
partage. Aucun de ces composants ne transmet de données personnelles à
des tiers dans le cadre de leur utilisation par cette application.
Aucun outil publicitaire, aucun outil d'analyse d'audience (analytics)
n'est intégré.

## Enfants

L'application ne collecte aucune donnée personnelle, quel que soit
l'âge de l'utilisateur. Son contenu (Bible, cantiques, dictionnaire
biblique, calendrier liturgique) convient à tous les publics.

## Modifications de cette politique

Cette politique peut être mise à jour si de nouvelles fonctionnalités
sont ajoutées à l'application. La date de dernière mise à jour figure
en haut de ce document.
