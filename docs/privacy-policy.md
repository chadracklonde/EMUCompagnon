# Politique de confidentialité — ÉMU Compagnon

*Dernière mise à jour : 30 octobre 2026*

## Résumé en une phrase

ÉMU Compagnon ne collecte aucune donnée personnelle : tout ce que vous
créez dans l'application (favoris, notes, surlignages, versets à
mémoriser, journal de prière, examens du soir, progression, réglages)
reste stocké uniquement sur votre appareil.

## Qui édite cette application ?

ÉMU Compagnon est développée par Chadrack Londe, à titre personnel,
pour la communauté de l'Église Méthodiste Unie. Ce n'est pas une
application commerciale.

Contact : chadracklonde@outlook.com

## Quelles données l'application stocke-t-elle ?

Toutes les données suivantes sont enregistrées **uniquement sur votre
appareil** (dans une base de données locale et dans les préférences de
l'application), jamais transmises à un serveur, jamais accessibles au
développeur :

- Les versets et les cantiques que vous marquez en favori
- Les notes personnelles que vous rédigez
- Les surlignages de couleur que vous appliquez aux versets
- Les versets que vous choisissez de mémoriser, avec leur calendrier de
  révision
- Les pages de votre journal de prière et de reconnaissance
- Vos réponses à l'examen du soir
- Votre progression dans le plan de lecture biblique
- Votre série de jours consécutifs d'utilisation, vos résultats au quiz
  quotidien et les défis de la semaine que vous avez marqués comme
  accomplis
- Vos préférences d'affichage (thème, taille du texte, langue, police)
- L'heure choisie pour le rappel de lecture quotidien

Aucune de ces informations n'est envoyée où que ce soit. Si vous
désinstallez l'application, ces données sont supprimées, sauf si vous
en avez conservé une sauvegarde vous-même (voir plus bas).

## L'application communique-t-elle avec un serveur ?

Deux situations impliquent une connexion réseau :

1. **Vérification des mises à jour de contenu** : à votre demande
   explicite (bouton « Vérifier les mises à jour » de l'écran
   « À propos »), l'application interroge un dépôt public sur GitHub
   pour savoir si une nouvelle version de la Bible, des cantiques ou du
   dictionnaire est disponible. Aucune donnée vous concernant n'est
   envoyée lors de cette vérification — l'application se contente de
   télécharger un fichier public. Comme pour toute connexion à
   un site web, GitHub reçoit l'adresse IP de votre connexion.
2. **Partage** : quand vous utilisez le bouton « Partager » (verset en
   image, sauvegarde de vos données), l'application ouvre le menu de
   partage natif de votre téléphone. Ce que vous choisissez de
   partager, et avec qui, dépend entièrement de vous — l'application
   elle-même n'envoie rien à un serveur.

Les polices de caractères sont intégrées à l'application : aucune
police n'est téléchargée depuis un service externe.

## Sauvegarde de vos données

L'écran « À propos » permet d'exporter vos données dans un fichier que
vous gardez vous-même (par exemple sur votre messagerie ou votre
espace de stockage), puis de le réimporter sur un autre appareil. Ce
fichier contient vos favoris, notes, surlignages, versets à mémoriser,
pages de journal, examens du soir et votre progression. **Il contient
votre journal personnel : ne le partagez qu'avec des personnes de
confiance.** L'application n'en garde aucune copie et ne l'envoie nulle
part.

## Notifications

Le rappel de lecture quotidien est programmé **entièrement sur votre
appareil**, sans passer par un serveur externe. Vous pouvez le
désactiver à tout moment dans les réglages.

## Permissions demandées

- **Notifications** : pour le rappel de lecture quotidien (optionnel,
  désactivable).
- **Accès à Internet** : uniquement pour la vérification des mises à
  jour de contenu, à votre demande.
- **Fichiers** : uniquement pour importer une sauvegarde que vous avez
  vous-même exportée précédemment, ou pour enregistrer les fichiers que
  vous partagez.

Aucune permission de localisation, caméra, microphone, contacts ou
identité n'est demandée.

## Services tiers utilisés

L'application utilise des composants techniques standards (bibliothèques
Flutter open source) pour le stockage local, les notifications et le
partage. Aucun outil publicitaire, aucun
outil d'analyse d'audience (analytics) n'est intégré.

## Enfants

L'application ne collecte aucune donnée personnelle, quel que soit
l'âge de l'utilisateur. Son contenu (Bible, cantiques, dictionnaire
biblique, calendrier liturgique) convient à tous les publics.

## Modifications de cette politique

Cette politique peut être mise à jour si de nouvelles fonctionnalités
sont ajoutées à l'application. La date de dernière mise à jour figure
en haut de ce document.
